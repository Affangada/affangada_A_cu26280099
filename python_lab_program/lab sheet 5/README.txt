MCA I Semester (Session 2026-2027)
Python Tuple Programs — Practical Assignment

This folder contains 25 separate Python programs based on the tuple program list.

How to run:
1. Install Python 3.
2. Open this folder in VS Code, IDLE, PyCharm, or another Python IDE.
3. Open any .py file and run it.
4. Programs that ask for input will show a prompt in the terminal.

Notes:
- Each program is saved in a separate numbered .py file.
- Program 14 adds only numeric values from a mixed tuple.
- Program 19 removes duplicates while preserving the original order.
- Program 24 finds common elements.
- Program 25 finds elements present in Tuple 1 but not in Tuple 2 (directional difference).
