COER UNIVERSITY — MCA I Semester (Session 2026-2027)
Lab Sheet-06: Python Programming Lab — Set Operations

This folder contains all 30 solved programs. Each solution is saved in a separate,
numbered Python (.py) file.

How to run:
1. Extract this ZIP file.
2. Open the folder in VS Code, IDLE, PyCharm, or another Python IDE.
3. Run any .py file using Python 3.

Important notes:
- Sets are unordered, so the display order may vary between runs.
- Program 5 uses remove(), which raises KeyError if the item is absent.
- Program 6 uses discard(), which does not raise an error if the item is absent.
- Program 19 generates the power set (all subsets).
- Program 27 uses Counter as well as sets because set comparison alone does not
  correctly check repeated-letter frequencies in anagrams.
- Program 23 removes duplicates; the order of the resulting list is not guaranteed.
