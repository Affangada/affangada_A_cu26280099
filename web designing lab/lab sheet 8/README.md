# Green Spoon Cafe — Lab Sheet 8

A responsive fictional cafe website built with semantic HTML5, CSS Grid/Flexbox and vanilla JavaScript.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in Chrome, Firefox, Edge or Safari.
3. Keep an internet connection for Google Fonts, Unsplash photos and the Google Maps embed.

## Files
- `index.html` — page structure, SEO metadata, accessible content, menu, testimonials, booking form, map and footer.
- `styles.css` — mobile-first styling, responsive breakpoints, grid/flex layouts, focus states and reduced-motion support.
- `script.js` — mobile navigation, hero carousel and client-side booking validation.
- `Project-Specification.md` — client brief and wireframe.
- `Design-Rationale.md` — design decisions and audience alignment.
- `Testing-Report.md` — practical testing checklist and expected results.
- `Presentation.pptx` — overview of planning, wireframe, development and testing.

## Notes
This is an educational front-end demonstration. The booking form validates in the browser but does not store or transmit reservations. Social links are generic platform links. Replace the sample address, phone, email and map location with real client details before deployment.
